# CloudCorp Records

**We run and secure the agents writing your code.**

CloudCorpHQ is the official GitHub organization for CloudCorp Records, founded by Rene Turcios in San Francisco.

AI agents now write a growing share of pull requests, run inside engineering toolchains, and interact with public surfaces at scale, with no governance layer. We build that layer.

## The fleet

28 open source MCP tools are live on npm under `@reneturcios/*` and on the official MCP Registry under `io.github.CloudCorpRecords/*`, with 20,749 downloads per month across 18 packages (verified October 26, 2026, window ending October 25, 2026).

- **PR and contribution ops:** Greenlight, claimcheck, prwatch, gatefile, shipcheck, cidiff, reprocheck, mcpaudit
- **Agent stack security:** hookcheck, actionpin, injectcheck, mcpvet, depguard, flowcheck, tracewatch, wallcheck
- **Catalog and connect spine:** ProdForge
- **Plus:** shelfsignal, opensourceit, inboxwatch, and the rest of the fleet

The full fleet lives today under [github.com/CloudCorpRecords](https://github.com/CloudCorpRecords) and stays there for now. Registry namespaces and package paths depend on those locations, so nothing moves until a transfer plan is verified per tool.

## The hosted platform

The paid product is the hosted layer on top of the open fleet: cloud runners, private repos, dashboard, history, alerts, and scheduled sweeps across three lines:

1. PR and contribution ops
2. Agent stack security
3. Exposure monitoring

Paid pilots run $500 to $2,000 per month for 60 days, one agent line, converting to annual platform contracts.

Flagship repo: [CloudCorpHQ/fleet](https://github.com/CloudCorpHQ/fleet)
